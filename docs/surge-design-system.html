Surge

A menu bar instrument for coding agents. It shows every agent you have running and the sub-agents and peers working beside it: how full each context window is, how fast tokens are flowing, what it's costing today, and which agent has stopped moving.

One system for three surfaces: the menu bar item, the popover (which can be detached as a panel), and a desktop widget in three sizes. Every rule cites the Apple Human Interface Guidelines page it comes from. Anything without a citation is a design judgment and is labeled as one.

Thesis

Quiet when everything is fine, loud only when an agent needs you.

People run Surge so they don't have to watch terminals. Most of the time the answer to "is anything wrong?" is no, and the interface should say that calmly: white numerals on near-black, with a small amount of color that tells you which provider is which. Two hues, orange and coral, are kept back for the moments that need attention. Because they're never used for anything else, they always mean something.

// 01

Two jobs for color

Four hues (lime, green, magenta, violet) identify providers. Two hues (orange, coral) mean "needs you soon" and "needs you now." The two sets never overlap (color.md › Best practices).

// 02

One meter, everywhere

The Fuse, the context meter, looks the same in the menu bar, popover, and widget, so it only has to be learned once (charting-data.md › Designing effective charts).

// 03

Meaning survives grayscale

Mac desktop widgets turn monochrome in vibrant mode. Every state has a shape, a symbol, and a word as well as a color (widgets.md › Using color).

// 04

Read-only, glanceable

No buttons in v0.2. Everything is information, and a click takes you to more of it (widgets.md › Adding interactivity).

Signature

The Fuse. Every agent's context window is drawn as a capsule with two notches cut at 70% and 90%. When an agent stalls, the fill freezes and becomes a coral hatch: a tripped fuse. Next to the reference's big light numerals and color bars, it's the one element that is specific to this product (design judgment, consistent with branding.md › Best practices: "Ensure branding always defers to content").

Wireframe review

An audit of surge-wireframe.html (AgentPulse × herdr), unchanged from v0.1 except where your revisions changed the fix. I read it from the source because it loads Tailwind and its fonts from a CDN, so contrast figures are computed from its hex values.

Summary — Critical issues

The wireframe has the right data model: an agent hierarchy, context pressure, stall detection, and spend. It also has two good instincts worth keeping: a hatch pattern for stalled agents and tabular numerals. But it's framed as an iOS home-screen widget when the product is a macOS menu bar app. Its 9 px text is below the macOS minimum. Status depends on color in places where macOS desktop widgets remove color. And it packs a three-tab app into a widget.

Critical

CriticalText is set at 9–10 px throughout the widget

Why: typography.md › Ensuring legibility: the macOS minimum is 10 pt. widgets.md › Displaying text in widgets: "In general, display text using fonts at 11 points or larger."

Fix: Widget text is 11 pt minimum. In the popover, 10 pt only for uppercase section labels and chart axis ticks. See Type.

CriticalSecondary labels fail contrast: zinc-500 #71717A on card #16181D is 3.67:1

Why: accessibility.md › Vision: text up to 17 pt needs 4.5:1. zinc-600 #52525B (used in a few places) is 2.30:1.

Fix: Secondary text is white at 70% (9.22:1 on the card) and tertiary is white at 55% (6.12:1).

CriticalProviders and states are told apart by hue alone

Model dots, colored progress fills, and concurrency bars encode meaning only in color. On Mac, desktop widgets render in the vibrant mode, which "desaturates text, images, and gauges", so the provider colors collapse to the same grey.

Why: accessibility.md › Vision: "Convey information with more than color alone." widgets.md › Rendering modes (Mac: vibrant on Desktop).

Fix: Providers get a dot and their name in text. Status gets an SF Symbol plus a word plus a shape change in the Fuse. Charts use direct labels and separators (charts.md › Color).

CriticalInfinite pulsing, ping, and border-flash animations

The radarPulse, animate-ping, and stuckBorderPulse animations loop forever, and none of them responds to Reduce Motion.

Why: accessibility.md › Cognitive: "Be cautious with fast-moving and blinking animations." motion.md: "generally avoid adding motion to UI interactions that occur frequently."

Fix: No looping animation anywhere. See Motion lab.

Improvements

HighWrong platform frame

It shows a 9:41 status bar, "iOS 18 WidgetKit", and iPhone widget sizes. The blueprint targets a non-sandboxed macOS app with MenuBarExtra and desktop widgets, and the menu bar surface isn't drawn at all.

Fix: Design for the menu bar item, the popover and detached panel, and the Mac desktop widget. Watch the 24 pt menu bar height (the-menu-bar.md › Menu bar extras).

HighThe widget is a small app: three tabs, expandable chips, scrolling lists

Why: widgets.md › Adding interactivity: "avoid creating app-like layouts in your widgets" and "reserve complexity for your app."

Fix: One widget in three sizes, with no tabs and no buttons. The tabs move into the popover.

HighAssumes per-second updates

The wireframe ticks uptime every second. Widgets "don't support continuous, real-time updates."

Fix: Show uptime and stall time with Text(date, style: .timer) so the system keeps them current (widgets.md › Updating widget content). Reload the timeline when an agent stalls or recovers, and show "Updated 2 min ago" when data is stale.

HighColor means several things at once

Green means OpenAI and also "healthy/optimal." Cyan means DeepSeek and also "current concurrency bar." Amber means "high context" and also half of the stalled hatch.

Why: color.md › Best practices: "Avoid using the same color to mean different things."

Fix: Hues are split into two disjoint sets: four for providers, two for status. See Color.

MediumA hand-drawn blur on the widget body

Why: liquid-glass.md › The two layers: glass belongs only to the functional layer, and the widget body is content.

Fix: Opaque #161617 cards. The popover's rim is the system's material. (The wireframe's dark look is kept, now as a deliberate choice. See Open questions.)

MediumJargon and mixed capitalization

"herdr", "Swarm", "Long-horizon mission", "DAG milestones", "lanes", "COMPACT SOON", "OPTIMAL", plus title case and sentence case mixed together.

Why: writing.md › Best practices: "Adopt capitalization rules that align with your app's style, then apply them consistently," and "Prioritize clarity and avoid the temptation to be too cute or clever with your labels."

Fix: Use the vocabulary in Writing: Agent, Sub-agent, Working, Waiting for you, Stalled.

MediumMonospace used as the default label face

Why: typography.md › Conveying hierarchy: "Minimize the number of typefaces you use." In the wireframe, mono is doing the job of hierarchy.

Fix: One sans family for everything. Mono only for paths, IDs, and // captions.

What works — keep it

  • A hatched fill for a stalled agent. A pattern survives grayscale, and it becomes the Fuse's tripped state.
  • Tabular numerals on every changing value.
  • The stalled state is shown on the agent's own row, in place (feedback.md › Best practices: "Consider integrating status feedback into your interface").
  • Context thresholds come with words, not just colors. Keep the idea, change the words.
  • The stacked cost bar has gaps between segments (charts.md › Color: "adding visual separation between contiguous areas of color").

Agents & status

Who is on screen, and what state they're in. Each state is carried by up to four channels at once: symbol shape, word, Fuse treatment, and (for two states only) color. Take any one channel away and the state still reads.

Hierarchy

workspace surge-widget $12.40 ├─ Agent Claude Sonnet Anthropic │ ├─ Sub-agent deepseek-reasoner DeepSeek │ └─ Sub-agent deepseek-chat DeepSeek └─ Agent Claude Sonnet Anthropic ← peer
  • Workspace: the project folder. Its name is the folder name and its path is shown in mono.
  • Agent: a top-level coding session. Two agents in the same workspace are peers and sit at the same level.
  • Sub-agent: a worker an agent spawned (a different model through the proxy, or a subagent folder). It's indented 14 pt under its agent with a hairline connector (layout.md › Visual hierarchy: "use indentation to convey hierarchy").
  • A sub-agent's state never changes its parent's. If anything inside a workspace needs you, the workspace header shows the symbol and a count.
  • Order: workspaces with something needing you come first, then by spend. Inside a workspace, agents needing you come first, and each agent's sub-agents follow it.

Rules

  • A text label always accompanies the Fuse: a percentage, plus a word at the thresholds (gauges.md › Best practices: "Write succinct labels that describe the current value").
  • Tripped is a pattern, not just a color, so it survives vibrant and grayscale rendering.
  • The axis is fixed at 0–100% of the model's window. Never rescale (charts.md › Axes: fixed range "when specific minimum and maximum values are meaningful").
  • The fill animates only when its value changes (0.3 s ease-out). It never pulses.
  • VoiceOver: "Context 72 percent of 200 thousand tokens, high."
  • SwiftUI: a custom GaugeStyle, so it stays a real Gauge for accessibility.

Components

The building blocks shared by the popover, the panel, and the widget. Use system controls wherever one exists (Button, Menu, DisclosureGroup, Gauge). The pill tabs, chips, Fuse, and charts are custom styling over standard behavior.

Agent and sub-agent rows

  • Line 1: state symbol · name (Body Medium) · trailing value: tok/s when Working, or the state word with its timer.
  • Line 2: provider dot and name in a fixed 78 pt column (Subheadline, secondary) · Fuse · context label. The fixed column keeps the Fuses aligned and keeps long model names on line 1 from being cut off.

  • Hover shows a 6% white fill (0.2 s). Keyboard focus shows the system focus ring. Return expands the row inline: tokens in, out, and cache, session ID, and working directory.
  • Secondary-click: Copy Session ID, Mute Alerts for This Agent, Reveal Working Directory in Finder.

Pill tabs and chips

  • Pill tabs switch the popover between Agents, Usage, and Spend. They behave like a standard tab group: ← → move between tabs, ⌘1–⌘3 jump, VoiceOver reads "Agents, tab, 1 of 3, selected."
  • The active pill is white with #161617 text (18.08:1). Inactive labels are white at 70%.
  • Chips filter the Agents list by workspace. They're toggle buttons. The count is part of the accessible name: "surge-widget, 3 agents."
  • Selecting "All" clears the others. Chips never change what an agent is, only what's shown.

Balances and provider legend

  • One row per account, showing the balance that provider reports. There is no combined total and no budget.
  • Rows read: provider dot · account name · amount (Title, tabular). The qualifier ("of $25 limit", "Low") goes in secondary text next to the name.
  • An account without a balance endpoint shows "Balance unavailable" in secondary text, with no color and no warning.
  • A mono caption underneath says how fresh the data is (// updated 12s ago). Balances poll every 60 seconds, per the blueprint.
  • Spend by provider (under Charts, below) uses the reference's proportional bar and a legend of dot, name, amount, and share.

Menu bar item

The menu bar is the product's resting state: one template glyph of up to four vertical mini-Fuses (the busiest agents), with an optional short readout. It's 22 pt tall inside the 24 pt menu bar (the-menu-bar.md › Menu bar extras). The menu bar is the system's, so it follows the system appearance and takes no Surge color.

Glyph rules

  • A template image (black and clear) so the system can recolor it for light and dark menu bars and the selected state (the-menu-bar.md › Menu bar extras). Exported as a custom SF Symbol with variable layers.
  • Bar height = context fill. A stalled agent's bar is drawn hollow with a dot, so the alarm is a shape change and stays readable in monochrome.
  • When anything needs you, a warning triangle and a count are appended. That's the only change.
  • Optional color: Settings › "Tint menu bar icon when an agent needs you" (off by default) tints only the triangle coral. Design judgment: the template rule wins by default.
  • Readout options (Settings): None · Agents · Spend. Never more than one number. The blueprint's "1 Orch · 2 Workers · $1.42" is too wide for a crowded menu bar, which the system will hide.
  • No animation in the menu bar, ever.

Click behavior

  • Click opens the popover (MenuBarExtra, .menuBarExtraStyle(.window)). HIG prefers a menu "unless the app functionality you want to expose is too complex for a menu." Surge's charts and live tree qualify.
  • Secondary-click opens a plain menu: Open Surge Panel, Pause Monitoring, Settings…, Quit Surge.
  • People choose whether the item appears. It's an onboarding toggle and a General setting (the-menu-bar.md: "Let people — not your app — decide").
  • Because the system can hide extras, everything is also reachable through a Dock menu, the panel, and a global shortcut people set themselves (the-menu-bar.md: "Avoid relying on the presence of menu bar extras").
  • Accessibility label: "Surge. 6 agents, 2 need you. 16 dollars 91 spent today."

Rules

  • The header status always says how many agents need you, as a word plus a symbol. When all is well it reads "All agents working" in secondary.
  • The tabs: Agents (tree + balances), Usage (throughput, tokens, context by agent), Spend (14-day daily spend, spend by provider, balances).
  • The popover grows with its content up to 720 pt, then scrolls. Changing tabs animates the height (popovers.md › Best practices: "Provide a smooth transition when changing the size of a popover").
  • Pin (macwindow.on.rectangle) detaches the popover. The detached panel looks the same plus a title bar: "Surge" (popovers.md › Desktop (macOS): "Make minimal appearance changes to a detached popover").
  • More (⋯) is a pull-down menu: Pause Monitoring, Settings… (⌘,), Quit Surge (⌘Q). Settings live in a standard settings window (settings.md).
  • Empty state: > no agents running_ in mono, then "Start Claude Code, or point workers at 127.0.0.1:8899." The next step is always on screen (writing.md › Best practices: "Provide clear next steps on any blank screens").

Rules

  • Text is 11 pt or larger. Readouts use Light at 22 pt and above (widgets.md › Displaying text in widgets).
  • Use the system content margins (tighter on the Mac desktop) and ContainerRelativeShape for inner shapes (widgets.md › Choosing margins and padding).

  • Data changes use .contentTransition(.numericText()), under 2 s.
  • The background is the dark card, set through containerBackground, so the system can still render it vibrant, tinted, or clear (widgets.md › Rendering modes).
  • In tinted or clear appearance the Fuse keeps its shape and the stalled hatch, and the status hues fall back to the tint (widgets.md › Accented: group content into accented and primary).

SwiftUI mapping

Tokens as code. Colors are asset-catalog Color Sets, fonts are bundled files, and everything else is system.

// Colors — Assets.xcassets (single appearance; High Contrast variants where noted)
//   Card #161617 · Lime #DFE301 · Green #03C37B · Magenta #FF79FB · Violet #A86BD6
//   Alert #FF7D6B (coral) · Caution #FFAA4F (orange)
enum Provider: CaseIterable {
    case anthropic, deepseek, openrouter, other
    var color: Color { switch self {
        case .anthropic:  Color("Lime")     case .deepseek: Color("Green")
        case .openrouter: Color("Magenta")  case .other:    Color("Violet") } }
    var name: String { switch self {
        case .anthropic: "Anthropic"  case .deepseek: "DeepSeek"
        case .openrouter: "OpenRouter"  case .other: "Other" } }
}
extension ShapeStyle where Self == Color {
    static var surgeCard: Color    { Color("Card") }
    static var surgeAlert: Color   { Color("Alert") }     // needs you now
    static var surgeCaution: Color { Color("Caution") }   // needs you soon
}
// Text: white at 100 / 70 / 55 %, stepping to 100 / 85 / 75 % under Increase Contrast
struct Ink { @Environment(\.colorSchemeContrast) static var contrast
    static func secondary(_ c: ColorSchemeContrast) -> Color { .white.opacity(c == .increased ? 0.85 : 0.70) }
    static func tertiary(_ c: ColorSchemeContrast)  -> Color { .white.opacity(c == .increased ? 0.75 : 0.55) } }

// Fonts — Beausite Classic is licensed; bundle the files in the app AND the widget extension.
// Info.plist (both targets): ATSApplicationFontsPath = "Fonts". If a file is missing, SwiftUI falls back to the system font.
enum Face: String { case light = "Beausite Classic Light", clear = "Beausite Classic Clear",
                         regular = "Beausite Classic Regular", medium = "Beausite Classic Medium" }
extension Font {
    static func surge(_ size: CGFloat, _ face: Face = .regular) -> Font { .custom(face.rawValue, fixedSize: size) } // no Dynamic Type on macOS
    static let readoutXL = Font.surge(40, .light)     // use .tracking(-0.03 × size) and .monospacedDigit()
    static let readoutL  = Font.surge(28, .light)
    static let readoutM  = Font.surge(22, .light)
    static let title     = Font.surge(15, .clear)
    static let body      = Font.surge(13)
    static let meta      = Font.surge(11)
    static let path      = Font.custom("Fira Code", fixedSize: 11)
}

// Agent state → presentation (one source of truth for every surface)
enum AgentStatus { case working, waitingForYou, stalled(since: Date), compacting, idle(since: Date), done, noSignal }
extension AgentStatus {
    var symbol: String { switch self {
        case .working: "bolt.fill"            case .waitingForYou: "hand.raised.fill"
        case .stalled: "exclamationmark.triangle.fill"  case .compacting: "arrow.down.and.line.horizontal.and.arrow.up"
        case .idle: "pause.fill"              case .done: "checkmark"       case .noSignal: "bolt.slash" } }
    var needsYou: Bool { switch self { case .stalled, .waitingForYou: true; default: false } }
}

// The Fuse — a real Gauge with a custom style
struct FuseGaugeStyle: GaugeStyle {
    var tripped = false
    func makeBody(configuration: Configuration) -> some View {
        GeometryReader { geo in
            let v = configuration.value
            ZStack(alignment: .leading) {
                Capsule().fill(.white.opacity(0.14))
                Capsule()
                    .fill(tripped ? AnyShapeStyle(HatchPattern(color: .surgeAlert))   // custom ShapeStyle: 45° stripes
                          : v >= 0.9 ? AnyShapeStyle(.surgeAlert)
                          : v >= 0.7 ? AnyShapeStyle(.surgeCaution) : AnyShapeStyle(.white))
                    .frame(width: geo.size.width * v)
                    .animation(.easeOut(duration: 0.3), value: v)
                ForEach([0.7, 0.9], id: \.self) { t in
                    Rectangle().fill(.surgeCard).frame(width: 1.5).offset(x: geo.size.width * t) }   // notches
            }
        }
        .frame(height: 6).clipShape(Capsule())
    }
}

// Pill tabs — standard behavior (tab traits, arrow keys), Surge styling
struct PillTabs: View {
    @Binding var selection: Tab
    @Namespace private var ns
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    var body: some View {
        HStack(spacing: 0) {
            ForEach(Tab.allCases) { tab in
                Button(tab.title) { selection = tab }
                    .buttonStyle(.plain).font(.surge(12, selection == tab ? .medium : .regular))
                    .foregroundStyle(selection == tab ? Color.surgeCard : .white.opacity(0.70))
                    .frame(maxWidth: .infinity, minHeight: 22)
                    .background { if selection == tab { Capsule().fill(.white).matchedGeometryEffect(id: "pill", in: ns) } }
                    .accessibilityAddTraits(selection == tab ? [.isSelected] : [])
            }
        }
        .padding(3).background(.white.opacity(0.10), in: Capsule())
        .animation(reduceMotion ? nil : .spring(duration: 0.26, bounce: 0.35), value: selection)
    }
}

Platform target: the blueprint says macOS 14+. The visual language here assumes macOS 26 system materials for the popover rim. On 14–15 the same tokens work, and the rim simply uses the older system material. Nothing in Surge depends on custom glass.

Open questions

  • Beausite Classic license. It's a commercial typeface. To ship it you need a license that covers embedding in a Mac app and in its widget extension (a separate bundle). I also need the real PostScript names and to check that it has tabular figures. If it doesn't work out, Inter Tight (free, open license) is a close substitute and is what these mockups use.
  • Dark cards in Light Mode. I kept the cards dark in both appearances, as the reference does. HIG prefers a light widget background in Light Mode (widgets.md › Rendering modes: "Prefer light backgrounds for the light appearance"), and a dark-only app is meant for rare cases (dark-mode.md). The cost of following HIG is a second set of hues, because lime and magenta can't hit 3:1 on white. Say the word and I'll add light variants.
  • Balances. The blueprint lists balance endpoints for DeepSeek and OpenRouter. I haven't verified what Anthropic offers, so its row shows "Balance unavailable" for now. I also dropped the Claude 5-hour and weekly plan gauges to keep v0.2 simple. They're easy to add back as a row in the balances card.
  • Sub-agents and peers. I read "sub-agents or peers" as: sub-agents are spawned by an agent (indented), and peers are agents at the same level in a workspace. Tell me if you meant something different, such as agents across different machines.
  • Stall threshold. The wireframe uses 120 s. Reasoning models can think silently for longer. Make it per-model in models-pricing.json (for example, 300 s for deepseek-reasoner).
  • App icon. Placeholder until you share yours.
